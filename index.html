MEOWKIT FIRMWARE

Update your MeowKit

Latest stable version: v1.0.0

Connect MeowKit to your computer using a USB data cable. Keep the device connected until installation is complete.

  1. Connect MeowKit to your computer.
  2. Click “Connect and install”.
  3. Select the MeowKit serial port.
  4. Confirm installation and wait for completion.
Please use Google Chrome or Microsoft Edge on a desktop computer. Firmware installation requires HTTPS.

Local test build: local-test-2026-09-05-symbol-keyboard (experimental)

Please use Google Chrome or Microsoft Edge on a desktop computer. Firmware installation requires HTTPS.

Installing factory or local test firmware may reset device settings. Do not disconnect the USB cable during installation.
